HOW TO UPDATE THE WEBSITE (two short uploads)
=============================================
Upload 1 of 2: open folder "1-pages-and-styles"
  - Select EVERYTHING inside it (the .html files plus the "css" and "js" folders) and drag it onto the GitHub upload page for your docs folder.
  - Commit changes.

Upload 2 of 2: open folder "2-slides-and-figures"
  - Drag the "assets" folder from inside it onto the same upload page.
  - Commit changes.

Both uploads go into the "docs" folder of the repository (page address ends in /upload/main/docs).
Files with the same name are replaced; new files are added. Nothing else needs to be deleted or touched.
After the green tick appears on the Actions tab, refresh the site with Ctrl+Shift+R.
